# Command Pattern 技术分享

这是一个基于静态 HTML 的技术分享演示文稿。

## 启动演示

请在仓库根目录 `d:\Workspace\hypersku-workspace-cli` 打开 PowerShell，启动本地 HTTP 服务：

```powershell
python -m http.server 8765
```

然后在浏览器打开：

<http://localhost:8765/slides/command-pattern-llm-tools/index.html>

不要直接双击 `index.html` 使用 `file://` 地址打开。演示文稿依赖仓库中的运行时脚本，浏览器可能会阻止本地文件加载脚本或打开演讲者模式窗口。

## 演示操作

请先点击演示页面，再使用以下快捷键：

| 按键 | 功能 |
| --- | --- |
| `←` / `→` | 上一页 / 下一页 |
| `Space` | 下一页 |
| `Home` / `End` | 第一页 / 最后一页 |
| `F` | 进入或退出全屏 |
| `S` | 打开演讲者模式 |
| `N` | 打开当前页讲稿 |
| `O` | 打开幻灯片总览 |
| `T` | 切换主题 |
| `R` | 在演讲者模式中重置计时器 |
| `Esc` | 关闭演讲者窗口或退出全屏 |

## 演讲者模式

按 `S` 后会打开一个新的演讲者窗口，包含：

- 当前页预览
- 下一页预览
- 当前页讲稿
- 演示计时器和翻页控制

如果按 `S` 没有反应，请检查浏览器地址栏是否拦截了弹出窗口，并允许 `localhost` 打开弹窗。演示者窗口与主演示窗口会同步翻页。

## 目录结构

- `index.html`：演示文稿内容
- `style.css`：本演示文稿的主题样式
