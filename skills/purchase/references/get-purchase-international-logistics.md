# get-purchase-international-logistics 输出参考

## 命令

```bash
hypersku-cli purchase get-purchase-international-logistics <orderId>
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 物流单号 | 国际物流运单号（Tracking Number） |
| 承运商 | 物流承运商名称（如 DHL/FedEx/UPS） |
| 仓库 | 始发仓库名称 |
| 时间 | 物流轨迹更新时间 |
| 内容 | 物流状态描述 |
| 位置 | 包裹当前所在位置 |

> **注意**：一个订单可能包含多个包裹，每个包裹独立展示其物流轨迹。
