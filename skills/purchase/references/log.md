# get-order-log 输出参考

## 命令

```bash
hypersku-cli purchase log <orderId>
```

## 输出示例

```markdown
|时间|状态|
|----|----|
|2024-01-01 10:00:00|待审核|
|2024-01-01 12:00:00|待采购|
|2024-01-02 09:00:00|采购中|
|2024-01-03 14:00:00|待发货|
|2024-01-04 08:00:00|运输中|
|2024-01-10 16:00:00|已完成|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 时间 | 状态变更时间 |
| 状态 | 订单流转状态，见 README.md 采购日志状态对照表 |
