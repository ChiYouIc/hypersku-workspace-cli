# get-order-address 输出参考

## 命令

```bash
hypersku-cli purchase get-order-address <orderId>
```

## 输出示例

```markdown
地址：XX市XX区XX路XX号
国家：中国
省份：广东省
市：深圳市
区：南山区
邮编：518000
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 地址 | 详细收货地址（街道/门牌号） |
| 国家 | 收货国家 |
| 省份 | 收货省份/州 |
| 市 | 收货城市 |
| 区 | 收货区/县 |
| 邮编 | 邮政编码 |
