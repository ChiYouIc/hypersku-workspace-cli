# get-order-info 输出参考

## 命令

```bash
hypersku-cli purchase info <orderId>
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 采购订单号 | Hypersku 系统内部订单号 |
| 客户订单号 | 客户侧订单号 |
| 下单时间 | 订单创建时间 |
| 仓库 | 发货仓库名称 |
| 金额 | 实际已支付金额（含商品金额+运费-折扣） |
| 运费 | 单独列出的运费金额 |
| 订单类型 | 见 SKILL.md 订单类型对照表 |
| 订单状态 | 见 SKILL.md 订单状态对照表 |
| SPU | 产品 ID |
| SKU | 商品 SKU ID |
| 名称 | 商品名称 |
| 类别 | 一级分类 二级分类 |
| 属性 | 商品规格属性（颜色/尺寸等） |
| 重量 | 单件商品重量（克） |
