# get-order-info-page 输出参考

## 命令

```bash
hypersku-cli purchase info page [flags]
```

## Flags

| Flag | 简写 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| `--page` | `-p` | int | 是 | 页码，默认 1 |
| `--limit` | `-l` | int | 是 | 每页条数，默认 10 |
| `--start` | | string | 条件必填 | 开始时间，格式 `yyyy-MM-dd HH:mm:ss` |
| `--end` | | string | 条件必填 | 结束时间，格式 `yyyy-MM-dd HH:mm:ss` |
| `--thirdOrderId` | | string | 条件必填 | 交易号 / 第三方订单号 |
| `--trackingNumber` | | string | 条件必填 | 物流单号 |

> **条件必填**：`--start` + `--end` 为一组，`--thirdOrderId`、`--trackingNumber` 各自独立；至少提供其中一组，否则报错"查询日期、交易号、物流单号不能同时为空"。

## 使用示例

```bash
# 按日期范围分页查询
hypersku-cli purchase info page --page 1 --limit 10 --start "2024-01-01 00:00:00" --end "2024-01-31 23:59:59"

# 按交易号查询
hypersku-cli purchase info page --thirdOrderId "TXN123456"

# 按物流单号查询
hypersku-cli purchase info page --trackingNumber "1Z999AA10123456784"
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 当前页码 | 当前查询的页码 |
| 页大小 | 每页返回的记录数 |
| 总数 | 符合筛选条件的总记录数 |
| 采购订单号 | Hypersku 系统内部订单号 |
| 客户订单号 | 客户侧订单号 |
| 金额 | 实际已支付金额 |
| 下单时间 | 订单创建时间 |
| 运费 | 运费金额 |
| 类型 | 订单类型（商品订单/集运/备货等） |
| 状态 | 订单状态（待审核/采购中/运输中等） |
| 仓库 | 发货仓库名称 |

> **注意**：分页查询仅返回订单概要信息，不包含商品明细、物流轨迹和地址。如需完整信息，请使用 `info <orderId>`。
