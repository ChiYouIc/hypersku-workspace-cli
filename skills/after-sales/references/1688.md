# get-1688-after-sales 输出参考

## 命令

```bash
hypersku-cli after-sales 1688 <thirdOrderId>
```

## 输出示例

```markdown
|退款ID|交易号|退款状态|退款类型|纠纷类型|当前操作|退款金额|退款运费|总退款金额|退货运费|创建时间|更新时间|剩余处理时间|
|----|----|----|----|----|----|----|----|----|----|----|----|----|
|REF001|1688ORDER001|等待卖家同意|售中退款|未收到货|请卖家处理|100.00|10.00|110.00|0.00|2024-01-05 10:00|2024-01-05 12:00|1天23小时|
|REF002|1688ORDER001|退款成功|售后退款|质量问题|退款完成|50.00|8.00|58.00|8.00|2024-01-10 14:00|2024-01-12 09:00|已完成|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 退款ID | 售后工单唯一标识（后续查询商品/详情/留言需使用） |
| 交易号 | 1688平台订单号/交易号 |
| 退款状态 | 当前退款状态描述 |
| 退款类型 | 售中退款 / 售后退款 |
| 纠纷类型 | 纠纷请求类型（如未收到货/质量问题等） |
| 当前操作 | 当前需要执行的操作 |
| 退款金额 | 商品退款金额 |
| 退款运费 | 退款的运费金额 |
| 总退款金额 | 合计退款金额 |
| 退货运费 | 退货产生的运费 |
| 创建时间 | 售后工单创建时间 |
| 更新时间 | 售后工单最近更新时间 |
| 剩余处理时间 | 剩余处理时限 |
