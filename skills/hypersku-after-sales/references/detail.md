# get-1688-after-sales-detail 输出参考

## 命令

```bash
hypersku-cli after-sales 1688 detail <refundId>
```

## 输出示例

```markdown
【售后详情】
退款ID：REF001
交易号：1688ORDER001
退款状态：等待卖家同意
退款服务：仅退款

退款说明：商品超过48小时未发货，申请退款
商品退款金额：100.00
退款运费：10.00
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 退款ID | 售后工单唯一标识 |
| 交易号 | 1688平台订单号 |
| 退款状态 | 当前退款状态描述 |
| 退款服务 | 退款服务类型（仅退款/退货退款等） |
| 退款原因 | 申请退款的原因 |
| 退款说明 | 退款补充说明 |
| 商品退款金额 | 商品退款金额 |
| 退款运费 | 退款的运费 |
| 退款总金额 | 退款合计金额 |
| 卖家 | 卖家公司名称 |
| 会员登录名 | 卖家1688登录名 |
| 手机 | 卖家手机号 |
| 电话 | 卖家固定电话 |
| 申请退款时间 | 退款申请提交时间 |
