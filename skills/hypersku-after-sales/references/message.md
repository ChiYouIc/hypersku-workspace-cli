# get-1688-after-sales-message 输出参考

## 命令

```bash
hypersku-cli after-sales 1688 message <refundId>
```

## 输出示例

```markdown
|留言时间|留言方|留言内容|操作留言|
|----|----|----|----|
|2024-01-05 10:30:00|buyer001|请问什么时候能处理退款？|买家催促退款|
|2024-01-05 14:00:00|seller001|您好，我们已收到您的退款申请，正在核实中。|卖家回复|
|2024-01-06 09:00:00|system|退款申请已超时，系统自动介入处理。|系统自动留言|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 留言时间 | 留言创建时间 |
| 留言方 | 留言者身份标识（买家/卖家/系统） |
| 留言内容 | 留言正文 |
| 操作留言 | 操作备注信息 |
