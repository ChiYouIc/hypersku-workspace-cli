# warehouses 输出参考

## 命令

`hypersku-cli extra-service warehouses <serviceId>`

`serviceId` 可从 `list` 命令结果获取。

## 输出示例

```
|仓储ID|仓储名称|服务名称|状态|
|----|----|----|----|
|101|深圳仓|质检贴标|启用|
|102|义乌仓|质检贴标|停用|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 仓储ID | 关联仓库 ID |
| 仓储名称 | 关联仓库名称 |
| 服务名称 | 增值服务名称 |
| 状态 | 启用 / 停用 |

无关联仓储时输出 `服务ID <N> 无关联仓储`。
