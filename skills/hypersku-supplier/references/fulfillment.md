# fulfillment 输出参考

## 命令

`hypersku-cli supplier fulfillment [--page <页码>] [--limit <每页条数>] [--name <供应商名称>]`

## 输出示例

```
当前页码：1，页大小：20，总数：2

|ID|供应商|已发货|未发货|平均时效|发货率|异常率|错发|少发|交易额|
|----|----|----|----|----|----|----|----|----|----|
|156|义乌市XX电子有限公司|350|6|2.8|98.5%|1.2%|2|1|258000.00|
|203|深圳市YY工艺品厂|115|5|3.5|96.8%|2.5%|1|2|98000.00|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| ID | 供应商 ID |
| 供应商 | 供应商名称 |
| 已发货/未发货 | 发货状态订单数 |
| 平均时效 | 平均发货时长（天） |
| 发货率 | 按时发货比率 |
| 异常率 | 异常订单比率 |
| 错发/少发 | 发货差错次数 |
| 交易额 | 统计期内交易金额 |
