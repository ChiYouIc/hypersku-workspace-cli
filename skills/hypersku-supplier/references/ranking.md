# ranking 输出参考

## 命令

`hypersku-cli supplier ranking [--page <页码>] [--limit <每页条数>] [--name <名称>] [--days <近N天>] [--sort <排序字段>] [--type <类型>]`

默认排序 `purTotal desc`（按采购量降序）。

## 输出示例

```
当前页码：1，页大小：20，总数：2

|ID|名称|城市|采购量|订单数|交易额|销售额|发货率|异常率|利润率|
|----|----|----|----|----|----|----|----|----|----|
|156|义乌市XX电子有限公司|金华市|12800|356|258000.00|301000.00|98.5%|1.2%|15.3%|
|203|深圳市YY工艺品厂|深圳市|5600|120|98000.00|112000.00|96.8%|2.5%|12.1%|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| ID | 供应商 ID |
| 名称 | 供应商名称 |
| 城市 | 供应商所在城市 |
| 采购量 | 统计期内采购商品总数 |
| 订单数 | 统计期内采购订单数 |
| 交易额/销售额 | 统计期内交易与销售金额 |
| 发货率 | 按时发货比率 |
| 异常率 | 异常订单比率 |
| 利润率 | 利润比率 |
