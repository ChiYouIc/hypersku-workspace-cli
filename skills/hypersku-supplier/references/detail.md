# detail 输出参考

## 命令

`hypersku-cli supplier detail <supplierId>`

## 输出示例

```
供应商ID: 156
名称: 义乌市XX电子有限公司
平台: 1688
平台登录ID: xyz_supplier
平台会员ID: b2b-1234567890
链接: https://xyz.1688.com
邮箱: contact@xyz.com
旺旺号: xyz_wangwang
联系人: 张三
联系人手机: 13800138000
微信: xyz_wechat
到货周期: 7 天
国家: 中国
省份: 浙江省
城市: 义乌市
地址: 义乌市国际商贸城A区
采购员: 李四
备注: 老供应商，合作3年
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 供应商ID | HyperSKU 内部供应商 ID |
| 名称 | 供应商名称 |
| 平台 | 采购来源平台（1688/京东/淘宝/天猫/拼多多/HyperFrom） |
| 平台登录ID | 平台上的登录账号 |
| 链接 | 供应商店铺链接 |
| 到货周期 | 预计到货天数 |
| 采购员 | 负责该供应商的采购员 |
