# spu-list 输出参考

## 命令

`hypersku-cli supplier spu-list [--page <页码>] [--limit <每页条数>] [--name <供应商名称>]`

## 输出示例

```
当前页码：1，页大小：20，总数：2

|ID|名称|SPU数|SKU数|类目|采购均价|
|----|----|----|----|----|----|
|156|义乌市XX电子有限公司|320|1560|手机保护壳|4.35|
|203|深圳市YY工艺品厂|85|240|家居摆件|12.80|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| ID | 供应商 ID |
| 名称 | 供应商名称 |
| SPU数 | 该供应商供货的 SPU 数量 |
| SKU数 | 该供应商供货的 SKU 数量 |
| 类目 | 主营类目 |
| 采购均价 | 采购平均单价 |
