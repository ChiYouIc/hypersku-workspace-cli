# list 输出参考（supplier）

## 命令

`hypersku-cli supplier list [--page <页码>] [--limit <每页条数>] [--name <供应商名称>]`

## 输出示例

```
当前页码：1，页大小：20，总数：2

--- 供应商 1 ---
ID: 156
名称: 义乌市XX电子有限公司
类型: 1
链接: https://xyz.1688.com
状态: 1
--- 供应商 2 ---
ID: 203
名称: 深圳市YY工艺品厂
类型: 1
链接: https://yy.1688.com
状态: 1
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 当前页码/页大小/总数 | 分页信息 |
| ID | HyperSKU 内部供应商 ID（可用于 `detail`） |
| 名称 | 供应商名称 |
| 类型 | 采购来源平台编号（1=1688、17=京东、18=淘宝、19=天猫、25=拼多多、99=HyperFrom） |
| 链接 | 供应商店铺链接 |
| 状态 | 供应商状态（1=正常） |

无数据时输出 `当前页码：N，页大小：N，总数：0` 及 `无数据`。
