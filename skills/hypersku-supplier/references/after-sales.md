# after-sales 输出参考（supplier）

## 命令

`hypersku-cli supplier after-sales [--page <页码>] [--limit <每页条数>] [--name <供应商名称>]`

## 输出示例

```
当前页码：1，页大小：20，总数：2

|ID|供应商|交易总数|成功|超时关闭|关闭|退款成功|退款失败|退款总数|
|----|----|----|----|----|----|----|----|----|
|156|义乌市XX电子有限公司|356|341|5|4|15|2|17|
|203|深圳市YY工艺品厂|120|110|4|3|8|1|9|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| ID | 供应商 ID |
| 供应商 | 供应商名称 |
| 交易总数 | 统计期内交易总次数 |
| 成功 | 交易成功次数 |
| 超时关闭/关闭 | 各类关闭的次数 |
| 退款成功/退款失败/退款总数 | 退款结果分布 |
