# tracking 输出参考

## 命令

```bash
hypersku-cli warehouse tracking <trackingNumber>
```

## 输出示例

```markdown

物流单号：73719940096786
快递签收：快递员已签收，签收人：仓库前台
快递签收时间：2026-07-28 10:32:15
仓库：深圳集运仓
仓库签收信息：仓库已签收
仓库签收时间：2026-07-28 14:05:22
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 物流单号 | 快递物流单号 |
| 快递签收 | 快递公司侧签收信息 |
| 快递签收时间 | 快递公司侧签收时间 |
| 仓库 | 仓库地址名称 |
| 仓库签收信息 | 仓库侧签收信息 |
| 仓库签收时间 | 仓库侧签收时间（为空时不展示） |
| 入库信息 | 入库状态描述 |
| 入库时间 | 包裹入库时间（为空时不展示） |
| 物流轨迹 | 仓库物流轨迹步骤，按时间正序排列 |
| 仓库操作 | 仓库操作记录，含操作时间和内容 |
