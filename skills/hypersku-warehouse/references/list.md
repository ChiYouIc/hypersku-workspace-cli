# list 输出参考（仓库）

## 命令

`hypersku-cli warehouse list --name <name>`

## 输出示例

```
当前页码：1，页大小：20，总数：3

|ID|仓库名称|联系人|联系电话|地址|状态|
|----|----|----|----|----|----|
|1|深圳仓|张三|13800138000|广东省深圳市宝安区|1|
|2|义乌仓|李四|13900139000|浙江省义乌市国际商贸城|1|
|3|香港仓|Wang|852-12345678|香港新界葵涌|1|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| ID | 仓库 ID |
| 仓库名称 | 仓库名称 |
| 联系人 | 仓库联系人 |
| 联系电话 | 联系电话 |
| 地址 | 仓库地址（省+市） |
| 状态 | 仓库状态（1=启用） |
