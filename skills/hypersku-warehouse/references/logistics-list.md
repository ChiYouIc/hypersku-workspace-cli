# logistics-list 输出参考

## 命令

`hypersku-cli warehouse logistics-list --name <name>`

## 输出示例

```
当前页码：1，页大小：20，总数：5

|ID|名称|别名|物流类型|报价方式|状态|
|----|----|----|----|----|----|
|101|顺丰速运|SF|0|1|1|
|102|圆通速递|YT|0|1|1|
|103|中通快递|ZT|0|1|1|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| ID | 物流线路 ID |
| 名称 | 物流公司名称 |
| 别名 | 物流公司简称 |
| 物流类型 | 物流类型编号 |
| 报价方式 | 报价方式编号 |
| 状态 | 线路状态（1=启用） |
