# inventory 输出参考

## 命令

`hypersku-cli ai-analysis inventory [flags]`

## 输出示例

```
当前页码：1，页大小：20，总数：32

|客户|商品|仓库|库存|15天消耗|预计可用天数|90天销量|库龄(天)|AI风险|AI摘要|
|----|----|----|----|----|----|----|----|----|----|
|john_shop|蓝牙耳机保护套|深圳仓|500|20|25|180|45|中风险 (2)|库存周转偏慢，建议促销|
|alice_store|手机壳透明|义乌仓|1200|80|150|600|120|高风险 (3)|严重滞销，90天销量仅600件，库存积压|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 客户 | 客户账号名 |
| 商品 | 商品名称 |
| 仓库 | 所在仓库 |
| 库存 | 当前库存数量 |
| 15天消耗 | 近 15 天消耗数量 |
| 预计可用天数 | 按当前消耗速度预计可用天数 |
| 90天销量 | 近 90 天销售数量 |
| 库龄(天) | 库存已存在天数 |
| AI风险 | AI 风险等级 |
| AI摘要 | AI 分析摘要 |
