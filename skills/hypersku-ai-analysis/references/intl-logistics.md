# intl-logistics 输出参考

## 命令

`hypersku-cli ai-analysis intl-logistics [flags]`

## 输出示例

```
当前页码：1，页大小：20，总数：45

|ID|客户|订单号|仓库|物流单号|物流公司|最新轨迹|状态|AI风险|AI摘要|
|----|----|----|----|----|----|----|----|----|----|
|1001|john_shop|34012345678|深圳仓|SF1234567890|顺丰速运|已到达目的国|运输中|中风险 (2)|该包裹在目的国海关滞留超过5天，建议联系当地清关代理|
|1002|alice_store|34012345679|义乌仓|YT9876543210|圆通速递|包裹已签收|已签收|低风险 (1)|物流轨迹正常，已按时签收|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| ID | 分析记录 ID |
| 客户 | 客户账号名 |
| 订单号 | HyperSKU 订单号 |
| 仓库 | 发货仓库名称 |
| 物流单号 | 快递运单号 |
| 物流公司 | 承运物流公司名称 |
| 最新轨迹 | 最新一条物流轨迹描述 |
| 状态 | 物流状态文本（运输中/已签收等） |
| AI风险 | AI 风险等级（无风险/低风险/中风险/高风险） |
| AI摘要 | AI 分析摘要（截断至 50 字符） |
