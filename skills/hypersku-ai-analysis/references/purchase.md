# purchase 输出参考

## 命令

`hypersku-cli ai-analysis purchase [flags]`

## 输出示例

```
当前页码：1，页大小：20，总数：32

|ID|来源|数据ID|交易号|物流单号|类型|风险|AI摘要|
|----|----|----|----|----|----|----|----|
|2001|物流异常|9001|6871234567890|SF1234567890|未签收|中风险|该包裹国内段显示签收但仓库未入库，疑似假签收，建议联系...|
|2002|1688售后|9002|6871234567891|YT9876543210|退件|高风险|供应商已收到退货但退款未在承诺时效内处理，建议跟进...|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| ID | 分析记录 ID |
| 来源 | 数据来源（物流异常 / 1688售后） |
| 数据ID | 关联业务数据 ID |
| 交易号 | 第三方平台交易号 |
| 物流单号 | 关联物流运单号（无则为空） |
| 类型 | 异常类型（未发货/无货/假发货/未到货/假签收/退件/丢件/未签收/未入库/丢包裹） |
| 风险 | AI 风险等级（已成功/中风险/高风险/无风险/监控中） |
| AI摘要 | AI 分析摘要（超过 50 字截断） |
