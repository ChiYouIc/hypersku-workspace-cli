# ali-refund-list 输出参考

## 命令

`hypersku-cli third-app-api ali-refund-list <orderId>`

按交易号查询该订单下的所有退款单（固定查询退款成功及退款中，queryType=3）。

## 输出示例

```
|退款单号|退款单ID|退款金额(元)|退款状态|产品名称|申请时间|完成时间|
|----|----|----|----|----|----|----|
|TQ302117834|302117834|15.80|退款成功|手机壳 透明款|2026-08-20 10:30:00|2026-08-22 15:10:00|
|TQ302119001|302119001|42.50|退款中|钢化膜 高清|2026-08-25 09:12:00||
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 退款单号 | TQ 前缀的退款单逻辑主键 |
| 退款单ID | 1688 退款单数字 ID |
| 退款金额(元) | 实际退款金额（分换算为元） |
| 退款状态 | 退款单当前状态 |
| 产品名称 | 退款商品名称 |
| 申请时间 | 退款发起时间 |
| 完成时间 | 退款完成时间（未完成为空） |
