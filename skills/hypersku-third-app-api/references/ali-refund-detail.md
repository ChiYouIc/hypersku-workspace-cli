# ali-refund-detail 输出参考

## 命令

`hypersku-cli third-app-api ali-refund-detail <refundId>`

`refundId` 为退款单逻辑主键，格式 `TQ+数字`（如 TQ123456）。

## 输出示例

```
退款单编号: 302117834
退款单逻辑主键: TQ302117834
退款状态: 退款成功
订单编号: 6871234567890
产品名称: 手机壳 透明款
申请退款金额: 1580 分 (15.80 元)
实际退款金额: 1580 分 (15.80 元)
申请原因: 七天无理由退换货
买家: buyer_test01
卖家: supplier_abc
申请时间: 2026-08-20 10:30:00
完成时间: 2026-08-22 15:10:00
类型: 退货退款
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 退款单编号 | 1688 退款单数字 ID |
| 退款单逻辑主键 | TQ 前缀的退款单逻辑主键（查询入参） |
| 退款状态 | 退款单当前状态 |
| 订单编号 | 关联的 1688 交易号 |
| 产品名称 | 退款商品名称 |
| 申请/实际退款金额 | 以分为单位存储，括号内换算为元 |
| 申请原因 | 买家填写的退款原因 |
| 买家/卖家 | 双方登录 ID |
| 申请/完成时间 | 退款发起与完结时间 |
| 类型 | 仅退款 / 退货退款 |
| 拒绝原因 | 卖家拒绝时的原因（未拒绝时不显示） |
