# ali-refund-operations 输出参考

## 命令

`hypersku-cli third-app-api ali-refund-operations <refundId>`

`refundId` 为退款单逻辑主键（TQ+数字）。固定查询第 1 页、每页 50 条。

## 输出示例

```
|时间|操作前状态|操作后状态|操作人|操作备注|
|----|----|----|----|----|
|2026-08-20 10:30:00|待卖家处理|卖家已同意|supplier_abc|同意买家的退货退款申请|
|2026-08-22 15:10:00|等待买家退货|退款成功|system|买家退货已签收，退款执行完成|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 时间 | 操作发生时间 |
| 操作前状态 | 操作前的退款单状态 |
| 操作后状态 | 操作后的退款单状态 |
| 操作人 | 执行操作的账号（买家/卖家/平台 system） |
| 操作备注 | 操作说明 |
