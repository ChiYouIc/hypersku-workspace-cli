# ali-order-detail 输出参考

## 命令

`hypersku-cli third-app-api ali-order-detail <orderId>`

## 输出示例

```
订单ID: 6871234567890
交易状态: success
总金额: 258.00
产品付款金额: 245.00
运费: 13.00
退款金额: 0.00
创建时间: 2026-08-15 10:30:00
付款时间: 2026-08-15 10:31:00
收货时间: 2026-08-22 14:20:00
买家: buyer_test01
卖家: supplier_abc

商品明细:
|名称|单价|数量|金额|子订单状态|
|----|----|----|----|----|
|手机壳 透明款|15.80|2|31.60|success|
|钢化膜 高清|8.50|5|42.50|success|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 订单ID | 1688 交易号 |
| 交易状态 | waitbuyerpay/waitsellersend/waitbuyerreceive/success/cancel 等 |
| 总金额 | 订单总金额（元） |
| 产品付款金额 | 产品实付金额（元） |
| 运费 | 运费金额（元） |
| 退款金额 | 已退款金额（元） |
| 买家/卖家 | 买家和卖家登录 ID |
| 商品明细 | 子订单商品列表（名称、单价、数量、金额、状态） |
