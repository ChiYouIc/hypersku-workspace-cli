# ali-logistics-trace 输出参考

## 命令

`hypersku-cli third-app-api ali-logistics-trace <orderId>`

## 输出示例

```
物流编号: 882011
物流单号: 480330616596
物流公司: 顺达物流
阿里状态: 已发货
仓库状态: 已入库
仓库名称: 深圳仓

物流轨迹:
|时间|轨迹|
|----|----|
|2026-08-15 10:30:00|卖家已发货，包裹已揽收|
|2026-08-16 22:15:00|包裹已到达深圳转运中心|

仓库物流轨迹:
|时间|轨迹|
|----|----|
|2026-08-18 09:00:00|包裹已到仓，待签收|
|2026-08-18 11:20:00|仓库已签收，入库扫描完成|
---
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 物流编号 | HyperSKU 物流记录 ID |
| 物流单号 | 1688 运单号 |
| 物流公司 | 承运物流公司名称 |
| 阿里状态 | 1688 平台侧物流状态 |
| 仓库状态 | HyperSKU 仓库侧状态 |
| 仓库名称 | 目的仓库名称 |
| 物流轨迹 | 平台侧完整运输节点（时间 + 描述） |
| 仓库物流轨迹 | 仓库侧操作轨迹（时间 + 描述） |
