# ali-logistics 输出参考

## 命令

`hypersku-cli third-app-api ali-logistics <orderId>`

## 输出示例

```
物流单号: 480330616596
物流公司: 顺达物流
发货状态: 已发货
订单号列表: 6871234567890
商品:
  - 手机壳 (数量: 2, 重量: 0.15)
  - 钢化膜 (数量: 5, 重量: 0.08)
---
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 物流单号 | 1688 运单号 |
| 物流公司 | 承运物流公司名称 |
| 发货状态 | 当前发货状态文本 |
| 订单号列表 | 关联的子订单号 |
| 商品 | 物流单包含的商品（名称、数量、重量） |
