# ali-mix-config 输出参考

## 命令

```bash
hypersku-cli third-app-api ali-mix-config --member-id <卖家memberId>
hypersku-cli third-app-api ali-mix-config --login-id <卖家loginId>
```

## 输出示例

```
卖家: b2b-1234567890
普通混批: true
混批金额: 500
混批数量: 10
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 卖家 | 卖家 memberId |
| 普通混批 | 是否开启普通混批（true/false） |
| 混批金额 | 混批起批金额（元） |
| 混批数量 | 混批起批件数 |
