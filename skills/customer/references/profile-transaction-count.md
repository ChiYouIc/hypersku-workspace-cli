# 客户交易统计 输出参考

## 命令

```bash
hypersku-cli customer profile transaction count <customerId> --start <startDate> --end <endDate>
```

## 输出示例

```markdown
【交易统计】
总交易额：123456.78
实际成交额：120000.00
退款金额：3456.78
总订单数：1520
退款订单数：12
客单价：78.98
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 总交易额 | 统计区间内订单交易总额 |
| 实际成交额 | 扣除退款后的实际成交金额 |
| 退款金额 | 统计区间内退款总额 |
| 总订单数 | 统计区间内订单总数 |
| 退款订单数 | 统计区间内退款订单总数 |
| 客单价 | 平均每单交易金额 |
