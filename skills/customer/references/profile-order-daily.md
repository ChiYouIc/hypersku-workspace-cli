# 客户日订单数量 输出参考

## 命令

```bash
hypersku-cli customer profile order daily <customerId> --start <startDate> --end <endDate>
```

## 输出示例

```markdown
总数：62
|日期|订单数|付款订单|履约订单|超期订单|退款订单|
|----|----|----|----|----|----|
|2026-08-20|32|30|28|2|1|
|2026-08-21|35|33|31|1|2|
|2026-08-22|28|26|25|1|0|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 总数 | 统计区间内的记录总数（按天） |
| 日期 | 统计日期 |
| 订单数 | 当日订单总数 |
| 付款订单 | 当日付款订单数量 |
| 履约订单 | 当日履约（发货完成）订单数量 |
| 超期订单 | 当日超期未处理订单数量 |
| 退款订单 | 当日退款订单数量 |
