# 查询客户档案 输出参考

## 命令

```bash
hypersku-cli customer detail <customerId>
```

## 输出示例

```markdown
【客户档案】
客户ID：1000249401
注册时间：2024-03-15 10:23:45
注册区域：US
最近登录时间：2026-08-25 09:12:33
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 客户ID | 客户唯一标识 |
| 注册时间 | 客户注册时间 |
| 注册区域 | 客户注册区域，可能为空 |
| 最近登录时间 | 最近一次登录时间 |

## 注意事项

1. 注册区域可能为空字符串。
2. 该命令展示客户基础档案；如需等级、周广告预算等运营信息，请使用 `hypersku-cli customer extends`。
