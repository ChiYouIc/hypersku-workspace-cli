# 查询客户档案 输出参考

## 命令

```bash
hypersku-cli customer detail <customerId>
```

## 输出示例

```markdown

客户ID：1000249401
是否有已支付订单：是
绑定店铺：3 家店铺

周广告预算：500-1000 USD

意向服务：1,2,3
【基础档案】
```

## 字段说明

| 分组 | 字段 | 说明 |
|------|------|------|
| 客户档案 | 客户ID | 客户唯一标识（平台 ID） |
| 客户档案 | 是否有已支付订单 | 是/否；true 表示已出池（拒绝触发） |
| 客户档案 | 绑定店铺 | 绑定店铺集合，可为 `-` |
| 问卷信息 | DS 经验 | 从事 Dropshipping 时长枚举文案，命中不了展示原始值 |
| 问卷信息 | 周广告预算 | 周广告预算枚举文案，命中不了展示原始值 |
| 问卷信息 | 月订单量预期 | 月订单量预期枚举文案，命中不了展示原始值 |
| 问卷信息 | 细分市场 | 1-10 枚举，展示原始数字 |
| 问卷信息 | 意向服务 | 多选逗号串（1 dropshipping / 2 DTC / 3 POD / 4 Merch / 5 Wholesale），可为 `-` |
| 基础档案 | 公司 | 公司名，可为 `-` |
| 基础档案 | 国家 | 国家名，可为 `-` |
| 基础档案 | 注册区域 | 注册区域，可为 `-` |
| 基础档案 | 注册时间 | 注册时间，可为 `-` |
| 基础档案 | 最近登录时间 | 最近一次登录时间，可为 `-` |
| 基础档案 | 用户等级 / 订单量级别 | L0 / O0 等级标识，可为 `-` |
| 基础档案 | 客户标签 | 0 默认 / 1 老用户 / 2 新用户 / 3 潜在用户 / 4 流失用户，命中不了展示原始值 |
| 渠道来源 | 渠道来源 | 渠道来源，可为 `--` |
| 渠道来源 | 渠道来源二级 | 渠道来源二级，可为 `--` |
| 渠道来源 | 渠道 Medium | 渠道 Medium，可为 `--` |
| 渠道来源 | 渠道 Campaign | 渠道 Campaign，可为 `--` |
| 渠道来源 | 合作来源代码 | 合作来源代码，可为 `--` |
| 渠道来源 | 渠道来源链接 | 渠道来源链接，可为 `--` |

## 注意事项

1. 该命令为 MCP 脱敏接口（`/outer/mcp/customer/profile/detail`），仅返回脱敏字段，不含邮箱、电话等 PII 原值。
2. 空值展示约定：普通业务字段为空显示 `-`，渠道来源字段为空显示 `--`。
3. 枚举字段（DS 经验/周广告预算/月订单量/客户标签）命中映射表时展示文案，未命中时展示原始数字。
