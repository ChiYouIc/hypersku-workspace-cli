# 查询客户信息 输出参考

## 命令

```bash
hypersku-cli customer info <customerId>
```

## 输出示例

```markdown
【客户信息】
客户ID：1000249401
等级：L6
订单等级：O5
最近30天订单数：19570
店铺数量：1
从事Dropshipping时长：多于1年
周广告预算：> 1000 USD
月订单量：500+
客户来源：官网注册
资料更新时间：2026-07-01 18:28:02
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 等级 | 客户等级（如 L1~L6） |
| 订单等级 | 客户订单等级（如 O1~O5） |
| 最近30天订单数 | 最近 30 天的订单数量 |
| 店铺数量 | 客户绑定的店铺数量 |
| 从事Dropshipping时长 | 枚举值：还没开始/少于6个月/6个月-1年/多于1年 等 |
| 周广告预算 | 枚举值：< 200 USD/200-500 USD/500-1000 USD/> 1000 USD 等 |
| 月订单量 | 枚举值：justStart/1-100/100-500/500+ |
| 客户来源 | 客户来源渠道，可能为空 |
| 资料更新时间 | 客户资料最近更新时间 |

## 注意事项

1. 枚举字段若返回未定义的值（如从事 Dropshipping 时长为 `0`），将直接展示原始数字。
2. 客户来源、资料更新时间可能为空字符串。
