# 客户画像 输出参考

## 命令

```bash
hypersku-cli customer profile order count <customerId> --start <startDate> --end <endDate>
```

## 输出示例

```markdown
【订单统计】
统计区间：2026-07-01 00:00:00 ~ 2026-08-27 00:00:00
总订单数：1520
日均订单数：24
日最大订单数：58
日最小订单数：3
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 统计区间 | 接口实际返回的统计起止日期 |
| 总订单数 | 统计区间内订单总数 |
| 日均订单数 | 平均每日订单数 |
| 日最大订单数 | 单日订单数最大值 |
| 日最小订单数 | 单日订单数最小值 |
