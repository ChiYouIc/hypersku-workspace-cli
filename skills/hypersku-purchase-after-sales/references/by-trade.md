## 命令

`hypersku-cli purchase-after-sales by-trade <tradeId>`

## 字段说明

| 字段 | 说明 |
|------|------|
| 工单号 | 采购售后工单编号 |
| 交易号 | 第三方平台交易号 |
| 快递单号 | 物流运单号 |
| 仓库 | 发货仓库 |
| 商品 | 商品名称和 SKU |
| 数量/金额 | 售后商品数量和金额 |
| 异常类型 | 异常分类（物流异常/质量问题等） |
| 状态 | 工单处理状态 |
| 处理人 | 负责处理的人员 |
| 客户 | 下单客户账号 |
