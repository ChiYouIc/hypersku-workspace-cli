# by-order 输出参考

## 命令

`hypersku-cli purchase-after-sales by-order <orderId>`

固定查询第 1 页、每页 20 条。

## 输出示例

```
订单号: 34012345678   共 1 条

【采购售后 1】
  工单号: PA20260903001
  交易号: 6871234567890
  快递单号: SF1234567890
  仓库: 深圳仓
  商品: 蓝牙耳机保护套 (SKU: BT-CASE-001)
  数量: 3   金额: 47.40
  异常类型: 少发
  状态: 已处理
  处理人: 赵六
  客户: john_shop
  创建时间: 2026-09-03 16:45:00
  备注: 供应商补发 1 件已到仓
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 工单号 | 采购售后工单编号 |
| 交易号 | 第三方平台交易号 |
| 快递单号 | 物流运单号 |
| 仓库 | 发货仓库 |
| 商品 | 商品名称和 SKU |
| 数量/金额 | 售后商品数量和金额 |
| 异常类型 | 异常分类（物流异常/质量问题/少发等） |
| 状态 | 工单处理状态 |
| 处理人 | 工单处理人 |
| 客户 | 客户账号 |
| 创建时间 | 工单创建时间 |
| 备注 | 补充说明（为空时不显示） |

无记录时输出 `订单号 <N> 无采购售后记录`。
