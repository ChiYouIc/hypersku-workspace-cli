# page-list 输出参考

## 命令

```bash
hypersku-cli domestic-third-trade-exception page-list [flags]
```

## Flags

| Flag | 简写 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| `--page` | `-p` | int | 是 | 页码，从 1 开始，默认 1 |
| `--limit` | `-l` | int | 是 | 每页返回的条数，默认 10 |
| `--hypersku-status` | `-s` | int | 是 | 异常主状态（见下方枚举） |
| `--hypersku-sub-status` | `-c` | ints | 是 | 异常子状态列表，默认 `[1,2]` |
| `--buyer-id` | `-b` | string | 否 | 买家 ID，仅返回该买家的异常订单 |

### 异常状态枚举

主状态（`--hypersku-status`）：

| 值 | 含义 |
|----|------|
| 1 | 未发货 |
| 2 | 假发货 |
| 3 | 未到货 |
| 4 | 假签收 |
| 5 | 未签收 |
| 6 | 退件 |
| 7 | 丢件 |
| 8 | 未入库 |
| 9 | 丢包裹 |
| 10 | 无货 |

子状态（`--hypersku-sub-status`，可传多个）：

| 值 | 含义 |
|----|------|
| 1 | 待处理 |
| 2 | 处理中 |
| 3 | 已处理 |
| 4 | 已关闭 |
| 5 | 已拒绝 |

## 使用示例

```bash
# 查询所有"丢包裹"且"待处理/处理中"的异常订单
hypersku-cli domestic-third-trade-exception page-list --hypersku-status 9 --hypersku-sub-status 1,2

# 按买家过滤并翻页
hypersku-cli domestic-third-trade-exception page-list -s 7 -c 1,2,3 -b 10001 -p 1 -l 20
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 当前页码 / 页大小 / 总数 | 分页信息 |
| MonitorOrderId | 监控订单 ID（订单在异常监控体系中的 ID） |
| MonitorLogisticsId | 监控物流 ID（物流记录 ID） |
| 交易号/1688订单号 | 第三方平台（1688/淘宝等）的交易号、采购订单号 |
| 商品数量 | 订单商品总数量 |
| 仓库 | 发货仓库名称 |
| 物流单号 | 国内段物流运单号 |
| 物流公司 | 物流承运商名称 |
| 订单付款时间 | 订单支付时间 |
| 创建时间 | 物流记录创建时间 |
| 更新时间 | 物流异常状态变更时间 |
| 状态 | 异常子状态中文名（待处理/处理中/已处理/已关闭/已拒绝） |
