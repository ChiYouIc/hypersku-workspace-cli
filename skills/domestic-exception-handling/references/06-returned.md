# 异常状态 - 退件

> 通用排查命令与字段说明见 [SKILL.md](../SKILL.md)
>
> **SLA**：确认退件后 72h 内完成与供应商沟通，7 天内完成退款/补发。
> **责任人**：采购专员。

## 异常说明
- **定义**：物流轨迹显示"退回"字样，快递正在返回商家。
- **典型成因**：
  - 商家发错收货地址
  - 收货地址无人签收/拒收
  - 包裹破损被快递退回
  - 快递超时未派送自动退回
  - 商家主动召回包裹

## 问题排查步骤

1. **查询物流轨迹，确认退件原因**：
   ```bash
   hypersku-cli logistics tracking <trackingNumber>
   ```
   关注轨迹中的退回原因备注。

2. **判断退件原因类型**：

| 退回原因 | 责任方 | 处理方向 |
|------|------|------|
| 发错地址 | 商家 | 商家承担，要求补发或退款 |
| 无人签收/拒收 | 仓库/物流 | 排查仓库是否正常收货 |
| 包裹破损 | 物流 | 联系物流理赔，同时联系商家补发 |
| 超时自动退回 | 物流/地址 | 确认地址无误后让商家重发 |
| 商家主动召回 | 商家 | 联系商家确认原因，协商处理 |

3. **查看退款状态**：
   ```bash
   hypersku-cli after-sales 1688 <thirdOrderId>
   ```
   确认是否已发起退货退款申请。

## 下一步处理步骤

| 序号 | 动作 | 说明 |
|------|------|------|
| 1 | **联系商家沟通** | 告知包裹已退回，根据退件原因协商处理方案 |
| 2 | **商家补发** | 商家责任（发错地址等）→ 要求商家重新发货 |
| 3 | **发起退款** | 商家无法补发 → 在 1688 平台发起退款，简要记录退款单号 |
| 4 | **换采** | 退款同时启动换采，找替代供应商下单 |
| 5 | **物流理赔** | 物流责任（破损等）→ 联系物流客服发起理赔 |

### 闭环条件
- 商家补发且有正常物流轨迹 → 异常关闭
- 退款到账 + 换采完成 → 异常关闭
