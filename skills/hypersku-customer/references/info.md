# get-customer-order-info 输出参考

## 命令

```bash
hypersku-cli customer order info <orderId>
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 客户订单号 | 客户侧订单号 |
| 订单金额 | 订单原始金额 |
| 实际金额 | 实际支付金额 |
| 运费 | 物流运费 |
| 增值服务费 | 品牌化/增值服务费用 |
| 税费 | 订单税费 |
| 关税 | 关税金额 |
| 币种 | 币种代码（如 USD/EUR/GBP） |
| 仓库 | 发货仓库名称 |
| 采购状态 | 对应采购订单的状态（如待审核/采购中/运输中/已完成） |
| 支付时间 | 客户支付时间 |
| 创建时间 | 订单创建时间 |
| SPU | 产品 ID |
| SKU | 商品 SKU ID |
| 名称 | 商品名称 |
| 属性 | 商品规格属性 |
| 图片 | 商品图片 URL |
| 数量 | 购买数量 |
| 销售价 | 商品销售单价 |
| 单价 | 商品成本单价 |
| 重量 | 单件商品重量（克） |
