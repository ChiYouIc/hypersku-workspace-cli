# 客户订单退件工单 输出参考

## 命令

```bash
hypersku-cli customer order return <customerOrderId>
```

## 输出示例

```markdown
【退件工单详情】
客户订单号:CUST202401010001
运单号:WB202401150001
快递单号:1Z999AA10123456784
客户单号:SHOP-10086
国家:US
入库时间:2024-01-16 10:20:30
创建时间:2024-01-15 09:00:00
工单类型:退件
工单状态:待处理
退件状态:已入库
说明:客户拒收，包裹退回仓库
留言:请联系客户确认退货原因
留言时间:2024-01-16 11:00:00
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 客户订单号 | 客户侧订单号 |
| 运单号 | HyperSKU 运单号 |
| 快递单号 | 尾程快递单号 |
| 客户单号 | 客户店铺侧单号 |
| 国家 | 收货国家代码 |
| 入库时间 | 退件入库仓库时间 |
| 创建时间 | 工单创建时间 |
| 工单类型 | 工单类型（如退件） |
| 工单状态 | 工单当前状态 |
| 退件状态 | 退件处理状态（如已入库） |
| 说明 | 退件原因说明 |
| 留言 | 最新留言内容 |
| 留言时间 | 最新留言时间 |
