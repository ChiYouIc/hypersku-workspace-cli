# 客户交易流水 输出参考

## 命令

```bash
hypersku-cli customer profile transaction bills <customerId> --start <startDate> --end <endDate>
```

> 注：金额列依次为 CNY/USD/EUR 三币种，格式为 `￥/$/€`。

## 字段说明

| 字段 | 说明 |
|------|------|
| 总数 | 统计区间内的记录总数（按天） |
| 日期 | 统计日期 |
| 订单数 | 当日订单总数 |
| 退款订单数 | 当日退款订单数量 |
| 交易额(￥/$/€) | 当日交易总额，依次为人民币/美元/欧元 |
| 实际成交额(￥/$/€) | 当日实际成交金额，依次为人民币/美元/欧元 |
| 退款金额(￥/$/€) | 当日退款总额，依次为人民币/美元/欧元 |
| 手续费(￥/$/€) | 当日交易手续费，依次为人民币/美元/欧元 |
