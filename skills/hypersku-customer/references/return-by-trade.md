# return-by-trade 输出参考

## 命令

`hypersku-cli customer order return-by-trade <tradeId>`

## 输出示例

```
交易号: 6871234567890   共 2 条

【退件工单 1】
  工单号: WO20260902001
  快递单号: YT9876543210
  仓库代码: YW01
  工单类型: 退件
  状态: 处理中
  创建时间: 2026-09-02 14:20:00

【退件工单 2】
  工单号: WO20260903001
  快递单号: ZT5555666677
  仓库代码: SZ01
  工单类型: 海外退件
  状态: 待处理
  创建时间: 2026-09-03 09:10:00
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 工单号 | 退件工单编号 |
| 快递单号 | 物流运单号 |
| 仓库代码 | 仓库编码 |
| 工单类型 | 退件类型（退件/海外退件/自取件等） |
| 状态 | 工单状态 |
| 创建时间 | 工单创建时间 |
