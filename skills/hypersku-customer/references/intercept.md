# intercept 输出参考

## 命令

`hypersku-cli customer order intercept <tradeId>`

## 输出示例

```
交易号: 6871234567890   共 1 条

【拦截工单 1】
  工单号: WO20260901001
  快递单号: SF1234567890
  仓库代码: SZ01
  状态: 待处理
  创建时间: 2026-09-01 10:30:00
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 工单号 | 拦截工单编号 |
| 快递单号 | 物流运单号 |
| 仓库代码 | 仓库编码 |
| 状态 | 工单状态（待处理/放行/拦截成功等） |
| 创建时间 | 工单创建时间 |
